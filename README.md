# Ivan Grigorenko

**UX/UI designer who works inside the repository: design systems, interfaces, and
prototypes built in code with AI tooling.**
Full-time since 2024 on B2B SaaS and consumer products, web and iOS. Building and
maintaining the design system the products run on, from the first screens to handoff
and design QA.

[ivangrigorenko.com](https://ivangrigorenko.com) · [LinkedIn](https://www.linkedin.com/in/ivan-grigorenko) · ivan.grigorenko.dsgn@gmail.com · Minsk

**Now:** most of the work runs through AI tooling — Claude Code against the
repositories, Figma MCP, prototypes generated into Storybook. The repositories below are
built that way.

## Projects

- **[VV Design System](https://github.com/tank-dsgn/vv-design-system)** — tokens on
  Tailwind's scales, 85 React components, 147 icons in two styles. Every state is
  documented in Storybook, and both themes pass accessibility checks on every story.
  [Live](https://vv-foundations.vercel.app)

- **[Portfolio site](https://github.com/tank-dsgn/ivangrigorenko-site)** —
  ivangrigorenko.com rebuilt from a Figma Sites export onto Next.js. The layout is
  generated from the export rather than written by hand, so the pages stay true to the
  design file, and a verification harness compares every page against the original by
  computed style. [Live](https://ivangrigorenko.com)

- **[Pot](https://github.com/tank-dsgn/pot-prototype)** — a clickable iOS prototype of a
  plant care app. It names a real plant from a photo and installs on iPhone as an app.
  [Live](https://pot-prototype.vercel.app)
